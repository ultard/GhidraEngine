# CLI

Исполняемый файл называется `ghidraengine` (цель CMake — `ghidraengine_cli`, собирается при
`GHIDRAENGINE_BUILD_CLI=ON`, это значение по умолчанию).

```
ghidraengine [OPTIONS] paths...
```

`paths` — один или несколько каталогов либо файлов. Отчёт идёт в stdout, прогресс — в
stderr, поэтому `ghidraengine D:/Photos > report.txt` работает как ожидается.

## Быстрый старт

```bash
# всё подряд в одной папке
ghidraengine D:/Photos

# только точные дубликаты, машиночитаемо
ghidraengine --exact-only -f json -o dupes.json D:/Photos

# строгий порог, повороты и отражения тоже считать дубликатами
ghidraengine -t 6 --rotations D:/Photos

# повторный скан почти бесплатен
ghidraengine --cache D:/Photos
```

## Что искать

| Флаг | Действие |
|---|---|
| `--exact-only` | только побайтово идентичные файлы |
| `--similar-only` | только перцептивно похожие |
| `--images-only` | пропустить видео |
| `--videos-only` | пропустить изображения |

`--exact-only` с `--similar-only` и `--images-only` с `--videos-only` несовместимы.

## Точность

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `-t, --threshold N` | 10 | расстояние Хэмминга из 64 бит; 6 — строже, 14 тянет чужое |
| `--color-threshold N` | 24 | максимальная разница цветности 0–255; 255 отключает проверку |
| `--rotations` | выкл. | считать дубликатами повороты и отражения |
| `--video-samples N` | 16 | ключевых кадров на видео, 1–32 |
| `--video-match F` | 0.65 | доля кадров, которая должна совпасть, 0–1 |
| `--subclips` | выкл. | искать ролик внутри более длинного (дороже) |
| `--verify` | выкл. | подтверждать точные дубликаты побайтовым сравнением |
| `--transitive` | выкл. | сливать кластеры транзитивно: полнота выше, риск цепочек тоже |

## Что обходить

| Флаг | Смысл |
|---|---|
| `--min-size N`, `--max-size N` | границы размера файла в байтах |
| `-x, --exclude GLOB` | глоб по полному пути, можно повторять |
| `--max-depth N` | глубина рекурсии, 0 — без ограничения |
| `--hidden` | не пропускать скрытые файлы |
| `--follow-symlinks` | ходить по символическим ссылкам |
| `--probe-all` | открывать все файлы, а не только с известными расширениями |

Тип медиа всегда определяется по содержимому; расширение решает лишь, открывать ли файл.

## Производительность

| Флаг | Смысл |
|---|---|
| `-j, --threads N` | рабочие потоки, 0 — автоопределение |
| `--cache` | кеш подписей; БД пишется в первый сканируемый каталог |
| `--cache-path FILE` | путь к БД кеша, включает `--cache` |

## Вывод

| Флаг | Смысл |
|---|---|
| `-f, --format {text,json,csv}` | формат отчёта, по умолчанию `text` |
| `-o, --output FILE` | писать отчёт в файл вместо stdout |
| `--keep {resolution,largest,oldest,newest,shortest}` | какой файл кластера считать основным |
| `-q, --quiet` | без индикатора прогресса |
| `--all-errors` | перечислить все нечитаемые файлы, а не первые 10 |

## Удаление

```bash
ghidraengine --delete D:/Photos            # сухой прогон: печатает, что удалил бы
ghidraengine --delete --confirm D:/Photos  # действительно удаляет
```

`--delete` без `--confirm` ничего не трогает. Удаляются все члены кластера, кроме keeper;
какой файл станет keeper, решает `--keep`. Сама библиотека не удаляет ничего — это делает
только CLI и только по явному `--confirm`.

## Коды возврата

| Код | Значение |
|---|---|
| 0 | успех, в том числе «дубликатов не найдено» и `--help` |
| 1 | скан не начался или не открылся файл `-o` |
| 2 | несовместимые флаги |
| ≥ 100 | ошибка разбора аргументов (коды CLI11: 106 — нет обязательного аргумента, 105 — не прошла проверка значения) |

Нечитаемые отдельные файлы кодом возврата не считаются: они попадают в раздел ошибок отчёта.

## Не-ASCII пути

Аргументы приводятся к UTF-8 на всех платформах, вывод в консоль Windows переключается в
кодовую страницу UTF-8. Пути с кириллицей, иероглифами и эмодзи работают без настройки.
